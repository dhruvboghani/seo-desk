How it works

From URL to fixed page in three steps.

Audit the page

Enter any URL. Rankdesk downloads it like Googlebot does and runs 24 checks, plus Google's own PageSpeed test.

Read the fix list

Problems are sorted by what to fix first. Each one says what is wrong and exactly how to fix it.

Open a tool and your site's details are already there. Copy the meta tags, schema or sitemap and paste them into your site.

What the audit checks

24 checks that decide whether Google can read, trust and show your page.

On the page 16

  • Title tag and meta description length
  • One H1 and a logical heading order
  • Alt text on every image
  • Canonical URL, language and charset
  • Open Graph, Twitter card and favicon
  • Valid JSON-LD schema
  • Word count and link text

Server & crawling 8

  • HTTP status code
  • HTTPS and the redirect chain
  • Server response time and HTML size
  • gzip or Brotli compression
  • noindex in tags or headers
  • robots.txt rules for this page
  • XML sitemap, and whether it lists the page

Speed from Google PageSpeed

  • Performance, SEO, accessibility and best-practice scores
  • Real-user Core Web Vitals: LCP, INP and CLS
  • Lab timings on mobile or desktop
  • The biggest speed fixes, with time saved
